# Professional Dashboard: ENGAGE Programme Performance Dashboard

## Overview
This project documents a professional reporting solution built to monitor programme performance and support informed decision-making in a project / programme / portfolio management context.

The dashboarding approach was used to improve visibility over programme performance and the performance of key offerings such as trainings, certifications, and broader programme activities.

## Objective
To provide a structured dashboard and reporting view that supports programme monitoring, management visibility, and decision-making.

## Business Context
Within a PMO / methodology support environment, management and stakeholders need a clear and reliable view of programme performance. Reporting was required not only for overall programme monitoring, but also for understanding how key offerings such as trainings and certifications were performing.

This work supported a more structured, data-driven approach to programme visibility and follow-up.

## Scope
The dashboard focused on:
- programme performance monitoring
- offering performance visibility
- trainings and certifications tracking
- management reporting
- structured KPI communication

## Work Completed
- Produced reports and dashboards using **Power BI**
- Built reporting systems from scratch using **Power BI and Excel dashboards**
- Supported monitoring of the programme and the performance of offerings such as:
  - trainings
  - certifications
  - programme activities
- Contributed to informed decision-making through structured reporting outputs
- Created a feedback mechanism using surveys to support data gathering and analysis

## Tools Used
- Power BI
- Excel
- survey-based data collection

This dashboarding work supported:
