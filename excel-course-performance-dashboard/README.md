# Professional Dashboard: Excel Course Performance Dashboard

## Overview
This project documents an Excel-based dashboard developed to monitor the performance of training courses through structured survey evaluation data.

The dashboard was created to provide a clear and repeatable way to assess course performance across multiple dimensions, including course quality, trainer performance, administration performance, and response rate. It combines survey scoring logic, Excel-based calculations, and dashboard reporting to support visibility over training effectiveness.

## Objective
To design and maintain an Excel dashboard that tracks course evaluation performance and supports monitoring of training quality and participant feedback.

## Business Context
In programme and training environments, collecting survey responses is useful only if the results can be transformed into meaningful performance indicators. This dashboard was built to convert raw survey feedback into a structured analytical view that supports follow-up, comparison, and reporting across courses.

The dashboard helped track how different courses performed over time and supported a more data-driven view of training delivery and participant satisfaction.

## Scope
The dashboard focused on:
- course performance
- trainer performance
- administration performance
- response rate
- participant / respondent tracking
- course-level comparison across sessions

## Data and Logic
The dashboard was supported by a structured Excel workbook including:
- an explanation sheet describing the evaluation logic
- a performance calculator sheet
- an evaluation survey data sheet
- a dashboard summary sheet

The scoring model converted survey responses into weighted values:
- Fully Agree = 1.0
- Agree = 0.5
- Partially Disagree = 0.0
- Fully Disagree = -0.5

These values were then aggregated and normalized to create comparable performance indicators.
